LenaGreen.com — GitHub Pages lander

Upload index.html, 404.html, CNAME and .nojekyll to the root of your GitHub Pages publishing source. Upload the extracted files, not the ZIP itself.

CNAME contains lenagreen.com. Configure your domain DNS for GitHub Pages and enable HTTPS when available. Keep your mail MX and TXT records in place.

index.html is the homepage. 404.html shows the same lander for unknown paths (with an HTTP 404 status). All styling is included; no build, external fonts, cookies or JavaScript are required.

The contact link opens the visitor's email application. Make sure hi@lenagreen.com can receive mail.

To edit the wording, change both index.html and 404.html. The page uses noindex to discourage search-engine indexing while serving as a temporary domain lander. Remove that meta tag if you want search engines to index it.
